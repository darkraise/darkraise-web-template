# UI proof: a closing layer ignores outside presses and focus moves

**Contract:** touch
**Fingerprint:** 2e3ce7a72e729794
**Judge:** ship 2e3ce7a72e729794 — docs/dforge/ui-ux/proofs/2026-11-11-closing-layer.judge.md
**Platform:** web
**Viewports:** 375x812, 1280x800
**Themes:** light, dark
**Evidence:** local

## Delta

**UI/UX depth:** touch — `DismissableLayer` ignores pointer-downs and focus moves outside it while its owner is closed and its content is still mounted for the exit animation, as it already did for Escape. No visual change.

- **UX-1** — A press outside a popover during its exit animation calls neither `onOpenChange(false)` nor `onInteractOutside`; the press reaches its target and the popover finishes closing.
- **UX-2** — Focus leaving a popover by Shift+Tab during its exit animation calls neither `onOpenChange(false)` nor `onInteractOutside`.
- **UX-3** — A press outside an open popover still dismisses it, with one `onOpenChange(false)` and one `onInteractOutside`.
- **UX-4** — Escape on an open popover still closes it with one `onOpenChange(false)` and returns focus to the trigger.
- **UX-5** — Every layer built on `DismissableLayer` gets the same behaviour: the primitive's unit tests cover a closing layer's pointer and focus paths, and the component suites of all ten consumers pass.
- **OP-1** — Proven at 375x812 and 1280x800, light and dark, with no accessibility violations on the probe and the open popover, no console errors and no horizontal overflow.
